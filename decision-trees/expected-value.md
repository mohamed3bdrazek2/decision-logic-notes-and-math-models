# Expected Value (EV)

The Expected Value is a key concept in decision trees, representing the probability-weighted average of all possible outcomes.

## Formula

The general formula for Expected Value is:

$$EV = \sum (P_i \times V_i)$$

Where:
* $P_i$ is the probability of outcome $i$.
* $V_i$ is the value (or payoff) of outcome $i$.
